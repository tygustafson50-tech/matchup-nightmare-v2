Matchup Nightmare V2
===================

Six-sport OVER-only research app. Designed for free local development without Replit AI credits.

Run: install Node.js 20+, then execute npm start and open http://localhost:3000
Tests: npm test

Supported sport tabs: NFL, NBA, MLB, NCAA men's football, NCAA men's basketball, men's soccer (seven leagues).

Current starter features: shared black/gold interface, unofficial public ESPN game schedules when reachable, selection of up to 16 games, manual player game logs, OVER hit rates, last-five/last-ten comparisons, basic manually supplied team scoring-defense similarity, historical 100% filter (at least 3 comparable games).

Important limitations: NO auto player logs, verified betting markets, alt lines, injuries, calibrated prediction model, validated defense-versus-position, or automatic picks yet. Manual entry is not verified data. ESPN public endpoints can be unreliable and are not a supported licensed sports-data contract. Historical trends do not equal predicted probabilities.

Upcoming: verified sport-by-sport data-provider coverage, automatic player logs, sport-specific comparable defenses, authorized prop feeds, backtesting and honest probability estimates.
